# AEROFIELD

Локальний сайт агросервісу, перенесений зі збереженого HTML-прототипу. Фірмовий дизайн і логотип збережені. Оригінал: `archive/aerofield-vizytivka.html`.

## Запуск

Для перегляду відкрийте `index.html` подвійним кліком. Так само можна відкрити `dist/index.html` або перенести всю папку `dist` на статичний хостинг.

Для розробки потрібен Node.js 22 або новіший. Зовнішніх пакетів немає. Після змін JavaScript у `src/` виконайте `node scripts/build.mjs`: він оновлює `public/app.js` і папку `dist`.

```sh
node scripts/serve.mjs
node --test
node scripts/build.mjs
```

Відкрити http://127.0.0.1:4173. Для перевірки збірки: `node scripts/serve.mjs dist` після зупинки попереднього сервера.

## Структура

- `index.html` — семантична розмітка й контент, доступні без JavaScript.
- `src/styles/main.css` — фірмові кольори, адаптивність, доступність.
- `src/features/calculator.js` — незалежний розрахунок та його інтерфейс.
- `src/features/leads.js` — підготовка заявки; окрема точка для майбутнього API.
- `src/main.js` — ініціалізація функцій та навігації.
- `public/assets` — ресурси, які браузер може кешувати окремо.
- `tests` — перевірки розрахунку та тексту заявки.
- `dist` — результат збірки для статичного хостингу, без архіву і службових файлів.

## Поточні обмеження

Форма готує текст і копіює його; вона не надсилає заявку. Контактів, погоджених тарифів і сервера немає. Калькулятор потребує введення тарифу: це площа × тариф, без логістики та препаратів. Шрифт завантажується з Google Fonts із системним запасним варіантом.

## Відео та новий дизайн

`src/styles/cinematic.css` — нове оформлення з великим відеоекраном. `src/features/video.js` — пауза, відтворення, зупинка відеофону за межами екрана та врахування reduced-motion / save-data. Відео в галереї завантажуються після взаємодії. Всі відео та обкладинки збережено локально в `public/media`; джерела та ліцензія — в `public/media/CREDITS.md`. Це ілюстративні стокові кадри, не роботи AEROFIELD і не підтвердження моделі XAG P100 Pro. На сайті це підписано.

Для заміни роликів використовуйте MP4 H.264 та відповідні JPG-обкладинки; збережіть назви файлів або оновіть посилання в HTML і CSS. Після заміни виконайте збірку. Скрипти `migrate.mjs` і `modernize.mjs` — одноразова історія перенесення, повторно їх не запускайте: вони перезаписують розмітку.

## Подальше масштабування

1. Для приймання заявок додати серверний API: перевірка даних, обмеження частоти, захист від спаму, збереження в базі, сповіщення менеджеру. Секрети зберігати лише на сервері. Повідомляти про успіх тільки після підтвердження API.
2. Тарифи перенести в керований каталог послуг; сервер має самостійно перевіряти ціни. Поточний розрахунок — лише попередня оцінка.
3. Додавати сторінки послуг і регіонів у міру появи реального контенту. При значному зростанні застосувати генератор статичних сторінок із шаблонами, зберігши незалежні модулі розрахунків.
4. Для кабінетів клієнтів чи диспетчеризації створити окремий застосунок із авторизацією та ролями. Маркетингову частину можна продовжувати роздавати через CDN.
5. Перед публікацією додати справжні контакти, політику обробки персональних даних, домен, canonical URL, sitemap і погоджені фото.

Публікація в інтернеті не виконувалась. Локальний сервер призначений для розробки.
